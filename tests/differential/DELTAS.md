# Intended differences: Rust engine vs the bash oracle

The goldens in `golden/` are the bash engine's output. The Rust engine must
reproduce every one byte for byte (canonical JSON for JSON output), EXCEPT the
cases listed here (machine-readable copy: `deltas.txt`). Each delta is one
reviewed finding. Its expected Rust output is committed as
`golden/<case>.delta.obs`. In gate mode the runner fails for a listed case with
no delta file, for a delta file equal to the bash golden (not a real
difference), and for a delta file not in `deltas.txt`. Any other difference is a
parity failure. `--oracle` re-checks bash against its own goldens, ignoring
deltas.

Expected `.delta.obs` files are written in the milestone that implements the
fix (M3 resolution, M4 capture/propose/install-signed). Until then each entry
names its cases and the bash evidence.
